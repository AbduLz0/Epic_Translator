# EPIC

An Android keyboard designed to transform ordinary words into
luxurious, elevated, and epic language using AI.

## Builds

- EPIC 0.1.0 — Initial version
- EPIC 0.2.0 — Updated version

## Installation

Download an APK from the repository's Releases page and install it
on your Android device.

## API

EPIC uses the Groq API. Configure your own API key in the app.
Never commit API keys or other secrets.
